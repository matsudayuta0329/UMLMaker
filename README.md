# UML Maker

Windowsでクラス図とシーケンス図を編集し、AIが読み取りやすいJSONとして保存するデスクトップアプリです。

## 主な機能

- クラス図: クラス名、構造化された属性・操作・引数、メモ、位置、関係タイプを編集
- 属性・操作・引数はUnity風の配列インスペクタで追加、選択、削除
- UML可視性 `public (+)`, `private (-)`, `protected (#)`, `package (~)` に対応
- クラス図は上下左右の接続点からドラッグして関係を作成。属性は `-`、操作は `+` で表示
- シーケンス図: オブジェクトの順番、メッセージ、タイプ、メモ、時系列位置を編集
- シーケンス図は送信元ライフラインから送信先ライフラインへドラッグしてメッセージを作成
- メッセージ追加に応じてライフラインとキャンバスを自動延長
- 編集状態を完全に保持するドキュメントJSON（`.umlmaker.json`）の保存、名前を付けて保存、インポート
- 座標・内部IDを除き、日本語で意味順に整理したAI指示用JSONをポップアップ表示してコピー
- 自動保存なし。新規作成時にもファイルを作りません
- レジストリ方式で図タイプを追加可能
- schemaVersion 1の文字列形式をschemaVersion 2の構造化メンバーへ自動移行

## 開発

```powershell
npm install
npm test
npm start
```

Windows向け成果物は `npm run pack:win` で `dist` に生成されます。

## JSON形式

保存用ドキュメントは `schema`, `schemaVersion`, `diagramType`, `metadata`, `elements`, `relationships`, `notes` を持ち、位置情報を含む編集状態を再現できます。

「ファイル → エクスポート → AI指示用JSONを表示」では、内部IDと座標を除いた日本語JSONを表示します。クラス図はクラス一覧の後に関係一覧、シーケンス図はオブジェクト一覧の後に時系列の処理フローを配置します。ファイルは作らず、「全文をコピー」からチャットへ貼り付けられます。

新しい図タイプは `src/core/diagram-types.js` で定義を登録し、レンダラーに対応する表示アダプターを追加します。
